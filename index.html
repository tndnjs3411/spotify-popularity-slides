Data Science Project Proposal

음악적 특성과 인기도의 관계

음악적 특성은 Spotify 곡의 인기도를 얼마나 설명하고 예측할 수 있을까?

"Can audio features predict Spotify track popularity, and how much predictive power do they provide?"

데이터 분석 및 시각화 음악 데이터 마이닝 머신러닝 기반 회귀 분석 모델 해석 및 성능 비교

←→ 키 또는 하단 버튼으로 슬라이드를 이동할 수 있습니다

Background & Motivation

왜 이 주제를 분석하는가?

곡의 인기는 음악 자체의 특성뿐 아니라 다양한 외부 요인의 영향을 함께 받습니다. 이 프로젝트는 그중에서 음향적 특성과 장르 정보가 플랫폼 인기도를 얼마나 설명하고 예측할 수 있는지에 집중합니다.

인기에 영향을 주는 요인들

아티스트 인지도, 홍보·마케팅, 발매 시점, 플레이리스트 노출과 같은 외부 요인과 함께, 곡 자체의 음향적 특성과 장르가 인기에 관여합니다.

인기도 점수의 의미

Spotify의 popularity(0~100)는 재생량과 최근 재생 추세 등을 반영하는 플랫폼 지표입니다. 곡의 객관적 품질이나 완성도를 뜻하지 않습니다.

연구 목표

음향 특성·장르 정보로 인기도를 설명하고 예측할 수 있는 범위를 탐색하며, 설명되지 않는 부분의 한계까지 논의합니다.

Research Questions

연구 질문과 분석 방법의 연결

RQ1

어떤 음악적 특성이 인기도와 가장 강한 관계를 보이는가?

danceability, energy, loudness, valence, tempo, acousticness 등을 중심으로 관계를 탐색합니다.

상관분석산점도분포 시각화히트맵
RQ2

음악적 특성만으로 인기도를 얼마나 정확히 예측할 수 있는가?

인기도를 연속형 예측 대상으로 두고 기준 모델과 선형·비선형 회귀 모델의 성능을 비교합니다.

회귀 모델 비교MAE / RMSE / R²
RQ3

장르·메타데이터를 추가하면 예측 성능은 어떻게 달라지는가?

음향 특성만 쓰는 모델(Model A)과 장르·explicit을 추가한 모델(Model B)을 동일 조건에서 비교합니다.

Model A vs B동일 데이터 분할·지표
RQ4

모델이 중요하게 본 특성과 설명되지 않는 부분은 무엇인가?

변수 중요도와 잔차 분석으로 예측 오차가 큰 곡의 특성을 살피고, 데이터에 없는 외부 요인을 논의합니다.

permutation importance잔차 분석
질문의 흐름: RQ1에서 관계를 탐색하고 RQ2에서 예측 가능성을 확인하며, RQ3에서 정보 추가 효과를, RQ4에서 해석과 한계를 다룹니다. 분석에서 얻은 상관관계를 인과관계로 해석하지 않습니다.

Spotify Tracks Dataset과 주요 변수

Spotify Tracks Dataset

Exploratory Data Analysis

탐색적 데이터 분석 계획 (EDA)

계획한 시각화와 각 그래프가 답하는 연구 질문을 정리합니다.

RQ1

인기도 분포 히스토그램

전체 인기도의 분포와 구간별 밀집도를 파악해 인기도가 편중된 구조인지 확인합니다.

RQ1

danceability × 인기도 산점도

대표 음향 변수와 인기도 사이의 선형·비선형 관계를 확인합니다.

RQ1

energy·loudness·valence × 인기도

여러 음향 변수와 인기도의 관계를 개별 그래프로 살펴 강한 관계의 변수를 탐색합니다.

RQ1

수치 변수 상관관계 히트맵

음향 변수 간 상관 구조와 인기도와의 상관 강도를 한눈에 파악합니다.

RQ3

장르별 인기도 분포 비교

장르에 따라 인기도 분포가 어떻게 다른지 확인해 장르 변수의 활용 가능성을 평가합니다.

RQ1·RQ4

인기도 구간별 음향 특성 차이

인기도 구간을 나눠 음향 특성 평균을 비교해 높은 인기도 곡의 특성을 살펴봅니다.

실제 그래프 결과는 분석을 수행한 뒤에만 보고합니다. 이 단계에서는 분석 방법과 목적만 제시합니다.

Machine Learning Plan

회귀 모델 학습과 평가 계획

기준 모델

학습 데이터의 평균 인기도를 모든 곡에 예측. 모델 개선 효과를 측정하는 기준선입니다.

선형회귀

변수와 인기도 사이의 기본적인 선형 관계를 평가합니다.

랜덤 포레스트

비선형 관계와 변수 간 상호작용을 탐색합니다.

그래디언트 부스팅

순차적인 오차 개선을 통한 예측 성능을 비교합니다.

학습·평가 절차

훈련/테스트 데이터 분리 → 훈련 데이터에서 교차검증으로 모델 설정 비교 → 동일한 테스트 데이터에서 최종 성능 평가. 전처리 정보가 테스트에 유입되지 않도록 방지합니다.

Model A

음향 특성만 사용

danceability, energy, loudness 등 수치형 음향 변수만 사용

VS
Model B

장르·메타데이터 추가

음향 특성 + track_genre + explicit

MAE

평균 절대 오차. 예측값과 실제값 차이의 평균

RMSE

제곱근 평균 제곱 오차. 큰 예측 오차에 더 큰 페널티

R²

모델이 설명하는 인기도 점수 변동의 비율

분석 전에는 특정 모델이 최고 성능을 낸다고 단정하지 않습니다.

AI Agent Workflow & Model Interpretation

AI 에이전트 활용 흐름과 모델 해석

1

데이터 확인

열과 자료형 탐색 코드 작성, 데이터 규모 확인

2

전처리

품질 검사, 결측치·중복 처리, 인코딩·스케일링

3

EDA

분포·관계 시각화 코드와 그래프 작성

4

모델 학습

회귀 모델 구현과 교차검증 비교

5

평가

MAE·RMSE·R² 계산 및 비교 표 작성

6

해석

변수 중요도·잔차 분석과 해석 보조

모델 해석 계획

  • permutation importance로 변수별 예측 기여도 평가
  • 실제 인기도와 예측 인기도의 관계 시각화
  • 잔차 분포로 오차가 커지는 구간 확인
  • 변수 중요도를 인과적 영향으로 해석하지 않음

검증 원칙

AI가 생성한 코드는 직접 실행하고, 결과와 가정이 올바른지 확인합니다. 오류 수정, 결과 검증, 재현성 점검 후 최종 발표 자료를 업데이트합니다.

AI 에이전트가 만들어 낸 가상의 분석 결과를 실제 데이터에서 얻은 결과처럼 사용하지 않습니다. 계획 단계에서는 목표와 방법만 제시하고, 수치와 결론은 분석 이후에만 보고합니다.
